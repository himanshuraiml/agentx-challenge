GitHub Starter Template

Accelerate your build phase. Clone our pre-configured repository containing agentic reasoning skeletons, environment variable configs, and tool-calling helpers.

Quick Start

We provide a Python starter template that contains a pre-built reasoning loop structure (ReAct pattern) and examples of binding APIs as tools. You can use it as a base for building your hackathon project.

Use GitHub Template Open in Google Colab (Zero-Install)

Local & Cloud Setup

You can clone the repository to your laptop, or run directly in Google Colab without downloading anything:

# 1. Clone the template repository
git clone https://github.com/himanshuraiml/agentx-starter.git
cd agentx-starter

# 2. Set up virtual environment
python3 -m venv venv
source venv/bin/activate

# 3. Install requirements
pip install -r requirements.txt

# 4. Initialize environment configuration
cp .env.example .env

# 5. Prove your setup works (no API key needed)
python main.py --dry-run "test"

Configure the .env file with free API credentials. We recommend Google AI Studio Gemini (GEMINI_API_KEY) or Groq Cloud (GROQ_API_KEY) for free, instant setup without credit cards.

Template File Structure

The repository layout is organized logically to separate the agent reasoning logic from tools and environments:

agentx-starter/ ├── agent/ │ ├── core.py # ReAct loop, step cap, repeat guard, error recovery │ ├── llm.py # Gemini / Groq wrapper with 429 retry │ └── prompt_builder.py # System prompt: set your theme's ROLE here ├── tools/ │ ├── __init__.py # Tool base class + registry (add your tools here) │ ├── calculator.py # Safe arithmetic │ ├── data_query.py # list_files, read_file, sql_query over CSVs │ └── web_search.py # DuckDuckGo search ├── config/__init__.py # Models, MAX_ITERATIONS, data folder ├── data/ # Sample data: replace with your theme's dataset ├── tests/test_agent.py # Offline tests (no API key) ├── notebooks/agentx_colab.ipynb ├── main.py # Entry point + judging contract (--json) ├── .env.example # GEMINI_API_KEY / GROQ_API_KEY ├── requirements.txt └── README.md

Starter Agent skeleton

Here is the core of the agent loop in agent/core.py:

def run(self, query, verbose=False):
    messages = [{"role": "user", "content": query}]
    trace, seen = [], {}
    for step in range(self.max_iterations):   # hard step cap
        reply = self.llm.generate(self.system, messages)
        data = parse_json(reply)
        if "final_answer" in data:               # Decision: done
            return data["final_answer"], trace
        name, args = data["action"], data.get("args", {})
        observation = self._call_tool(name, args)  # Action -> Observation (errors become text)
        trace.append({"thought": data.get("thought"), "tool": name,
                      "args": args, "observation": observation})
        messages += [{"role": "assistant", "content": json.dumps(data)},
                     {"role": "user", "content": f"OBSERVATION: {observation}"}]
    return self._wrap_up(messages), trace

Add a tool by subclassing Tool in tools/ and registering it in build_tools().

Judging contract: python main.py --json "<query>" must print one JSON line {"answer": ..., "trace": [...]} and read data from AGENTX_DATA_DIR. The starter already does this. See Backend Contract.
