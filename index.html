What counts as an agent

Wrapper or agent? The loop decides.

Judges read your execution trace. If your system doesn't run this loop with real tools, it's a wrapper, and wrappers are capped at 40%.

01

Thought

Plan the next move from the goal and what's known so far.

➔
02

Action

Choose a tool dynamically and call it with real arguments.

➔
03

Observation

Read the tool output, including errors and empty results.

➔
04

Decision

Loop again, retry, or synthesize the final answer.

Anti-wrapper judging

How you're scored

Judges inspect terminal logs and execution traces, not just the UI.

Agentic architecture & autonomy40

Plans before acting, chooses tools dynamically, handles tool failures and retries.

Domain utility & execution30

Solves the chosen problem realistically using real datasets or APIs, not hardcoded strings.

Code hygiene & system design20

Clean split between agent brain, tool registry and execution driver. Repo runs from the README.

Presentation & live demo10

Clear explanation, and every team member can answer technical questions.

40% ceiling. Forwarding prompts to an LLM with no decision loop, no tool execution, or mocked tool outputs caps your score at 40 out of 100.

Mentors, not code-writers

8–10 senior CSE / IT / AI students, roughly 1 per 4–5 teams. They unblock Python environments, 429 rate-limit errors, and tool-calling JSON schema bugs. You write the agent.

Fallbacks are ready

Lab PC without Python 3.10 or admin rights? Switch to Colab. Rate-limited? Swap providers or take a reserve key. Wi-Fi blocked? Mobile hotspots are on hand.

Stuck in a loop?

Cap iterations (max_iterations = 5) and tell the model to answer with what it has after repeating the same tool twice.

Clarifications

Frequently asked questions

Who can participate?

B.Tech students of SRMIST Tiruchirappalli from any branch and any year. Teams have 2 to 4 members.

Where is it held and how long?

In person on 30 October 2026 in the campus central computer labs, with the finale in the auditorium. It runs about 8 hours in total, with a 6-hour build window from 09:45 to 15:45.

Do I need paid API keys or a credit card?

No. Use the free tiers of Google AI Studio and Groq. Never enter card details. A Colab notebook is provided, so no local installs are needed.

What counts as an agent versus a wrapper?

An agent runs an iterative reasoning loop (Thought, Action, Observation, Decision) and dynamically calls real tools on real data. Wrappers and hardcoded tool outputs are capped at 40%.

How does elimination work?

Round 1 at Hour 3 is a pass or probation check. Round 2 at Hour 5.5 scores your autonomy loop out of 50 and selects the top 6–8 finalists. Round 3 is the live stage pitch.

What do I submit?

By code freeze at 15:45: a GitHub repo, a system diagram, and a 2-minute demo link (Loom or Drive), submitted via Google Form. See the submission rules.
